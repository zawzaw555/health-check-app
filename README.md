# Health Check App

## Overview
Health Check management system を Spring Boot と MyBatis　で開発する。

## Features
 - Login & Logout
 - Health check List
 - Health check Detail
 - Health check record registration
 - Health check record update
 - Health check record deletion
 - Health check history search

## Technology
 - Java 21
 - Spring Boot
 - Thymeleaf
 - MyBatis
 - H2 Database
 - Bootstrap

## Database
 - H2
