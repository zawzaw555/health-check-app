# Health Check App

## Overview
Health Check management system を Spring Boot と MyBatis　で開発します。

## Features
 - Login
 - Health check List
 - Logout
 - Health check Detail
 - Health check record registration
 - Health check record update
 - Health check record deletion
 - Health check history search

## Technology
 - Java 21
 - Spring Boot
 - Thymeleaf
 - MyBatis
 - PostgreSQL
 - Bootstrap

## Database
 - PostgreSQL
